# GTA 6 Meme Submission

This repository contains the make.fun submission entry for the GTA 6 meme.

## Structure

- `meme.png`: The GTA 6 meme image asset.
- `POST.json`: Submission metadata containing the target X/Twitter status URL.
- `main.ts`: Submission script that validates `POST.json` and copies it to the make.fun output directory.
- `.makefun/owner.json`: Owner configuration for the make.fun bot.
- `LICENSE`: Project license.
